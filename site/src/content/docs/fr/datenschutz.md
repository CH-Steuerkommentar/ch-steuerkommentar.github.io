**Pas de cookies, pas de suivi.** Le site ne requiert aucune inscription, ne dépose pas de cookies et n'utilise aucun service d'analyse ou de suivi. La recherche s'effectue uniquement dans votre navigateur.

**Hébergement.** Le site est hébergé par GitHub Pages (GitHub, Inc., États-Unis). GitHub traite les données techniquement nécessaires, comme l'adresse IP, pour afficher les pages ; des données sont ainsi transmises aux États-Unis. La police est chargée depuis le serveur de l'Université de Saint-Gall.

**Vos droits.** Vous pouvez demander des renseignements sur vos données personnelles ainsi que leur rectification ou leur effacement à [sekretariat-ile@unisg.ch](mailto:sekretariat-ile@unisg.ch?subject=%5BILE-StK%5D%20Protection%20des%20donn%C3%A9es). La [déclaration de protection des données de l'Université de Saint-Gall](https://www.unisg.ch/de/datenschutzerklaerung/) s'applique en complément.
